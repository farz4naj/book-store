# book-store
The Biok Store 📚

The Biok Store is a simple and elegant bookstore landing page designed for a bookstore located in Kabul, Afghanistan.

Features

• Navigation bar created using CSS Flexbox.
• Hero section with a bookstore image.
• About section introducing the bookstore.
• Book collection and categories.
• Image gallery created using CSS Grid (rows and columns).
• Customer testimonials.
• Contact form.
• Footer with bookstore information.

Technologies Used

• HTML5
• CSS3
• CSS Flexbox
• CSS Grid

Project Goal

The goal of this project is to practice HTML semantic elements, CSS styling, Flexbox, and Grid while creating a simple bookstore website.

Location

Kabul, Afghanistan.
